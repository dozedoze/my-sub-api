让模型联网（所有用户共用）

用户自己接 MCP

MCP 是给模型接外部工具的服务（比如查文档、查数据库）。用户在聊天页「扩展」里自己添加，由网关代为连接。地址只能是公网 https 域名，不能是 IP、内网或本站。每个用户最多 8 个 MCP、20 个 Skill。具体谁配了什么，看左侧「用户配置」。

上游账号

账号池、余额、拉黑，以及 auto 分档。点击模型名即可复制。

账号池

同一 Base URL 的多个上游账号会轮询。上游返回 429 时切换账号；401 / 403 会拉黑该账号后再切换。签发时锁定上游的 Key 不参与轮询。
